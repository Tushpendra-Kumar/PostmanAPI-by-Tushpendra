## 📌 Overview

A standardized, comprehensive **Postman Collection** for automating RESTful API verification, endpoint testing, and request validation for a Book Store application.

---

## ✨ Key Features

- **Complete CRUD Suite:** Pre-configured HTTP requests for GET, POST, PUT, and DELETE operations.
- **Automated Assertions:** JavaScript test scripts verifying status codes (200 OK, 201 Created, 400 Bad Request, 404 Not Found) and response JSON schemas.
- **Environment Variable Support:** Dynamic variable injection for `base_url`, `auth_token`, and resource IDs.
- **One-Click Import:** Ready to import directly into the Postman desktop app or CLI runners (Newman).

---

## 💻 Tech Stack & Architecture

- **API Tooling:** Postman v10+, Newman CLI
- **Standards:** RESTful Architecture, JSON Schema Validation

---

## 🚀 Getting Started

### Prerequisites
Postman Desktop App installed or Newman CLI.

### Installation & Setup
```bash
# 1. Clone this repository
git clone https://github.com/Tushpendra-Kumar/PostmanAPI-by-Tushpendra.git

# 2. Navigate into project directory
cd PostmanAPI-by-Tushpendra

# Import into Postman: Open Postman -> Click Import -> Select 'Book API.postman_collection.json'
```
